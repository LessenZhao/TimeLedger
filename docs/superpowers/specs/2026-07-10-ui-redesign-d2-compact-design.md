# TimeLedger UI 改版规格（方向 A · D2 紧凑）

日期：2026-07-10
状态：已确认（用户「可以」）
范围：今天主路径视觉与信息架构；先不改业务逻辑

## 1. 目标

把「后台模板感」改成可用的低摩擦打标页：

- 项目列表是主路径，占最大面积
- 未记录只作扫读上下文，不大号标题
- 去掉主屏噪音（搜索/添加常驻、已记录、草稿数、页面标题「今天」）

## 2. 今天页结构（三层）

```
┌─────────────────────────────────────┐
│ 撤销     未记录 1h 23m        💡/确认 │  ← 状态条（矮）
├─────────────────────────────────────┤
│        [  项目  |  时间线  ]         │  ← 整宽 Segment
├─────────────────────────────────────┤
│ 项目行 / 时间条目（主空间）            │
│ ... 尽量多可见行                     │
└─────────────────────────────────────┘
│ 今天 | 复盘 | 设置                   │  ← Tab 不变
```

### 2.1 状态条

| 元素 | 规则 |
|------|------|
| 未记录 | 必须在状态条；文案 `未记录` + 时长**同一行**；字号约 13pt；数字 semibold + 等宽；**禁止**大号英雄数字、禁止折成两行 |
| 左侧 | `撤销`（不可用时 disabled） |
| 右侧 | 项目模式：`💡` 快速想法；时间线模式：`确认`（确认草稿） |
| 不显示 | 页面标题「今天」、已记录合计、草稿数量 |

### 2.2 Segment

- 文案：`项目` | `时间线`（替换「待办」）
- 整宽、独立一行；高度约 30pt；字号约 12pt
- 与未记录**不**挤在同一基线抢宽度

### 2.3 项目列表（主路径）

| 规则 | 说明 |
|------|------|
| 行高 | 紧凑，可视约 44–48pt（可点下限） |
| 左 | 色块 28×28 + emoji（有则显示） |
| 中 | 项目名 14pt semibold；副文案 11pt：`分类 · 今日累计`（无累计显示 `—`） |
| 右 | 小圆钮 ＋ 28×28；点击 = 快速归档；长按 = 调整时间段 |
| 列表 | 去掉首页常驻搜索栏、添加项目栏 |
| 入口 | 「管理」链到项目管理；空状态主按钮「添加项目」 |
| 提示 | 底部小字：`轻点归档 · 长按调整` |

### 2.4 时间线列表

- 同一状态条 + Segment 骨架
- 条目：项目名、时段、时长、草稿/已确认标记；有思考显示条数
- 草稿视觉弱化（降低不透明度或次要色）
- 点进编辑；右上/右侧「确认」= 确认当日草稿
- 去掉底栏四格统计（未记录/已记录/现在/剩余）

## 3. 视觉（D2 柔和 iOS）

- 背景：系统分组灰 `#F2F2F7` 或等价
- 卡片：白底、圆角约 10pt、轻分隔，避免过重阴影
- 强调色：系统蓝，仅用于主操作（＋、链接、选中 Tab）
- 项目色：低饱和色块底，不与大蓝钮抢视线
- 全页字号偏小一档；信息靠字重/颜色分层，不靠放大

### 建议 token（实现时可集中）

| Token | 约值 |
|-------|------|
| 正文/未记录 | 13 |
| 项目名 | 14 semibold |
| 副文案 | 11 |
| Segment | 12 / 高 30 |
| 行距 | 列表 gap 5；行 padding 垂直 8 |
| 色块/＋ | 28×28 |

## 4. 交互（行为不变，反馈补齐）

| 操作 | 行为 |
|------|------|
| 点 ＋ | 快速归档未记录到该项目；轻触反馈；未记录数字更新 |
| 长按 ＋ | 打开调整时间 Sheet |
| 未记录超时 | 仍走现有阈值 → 调整 Sheet |
| 💡 | 快速想法 Sheet |
| 确认 | 确认当日草稿 |
| 撤销 | 撤销上一条（现有逻辑） |

## 5. 本阶段明确不做

- 时间色带 / 完整日时间轴可视化（方向 B）
- 深色「墨夜」皮肤
- 复盘大图表重做（可后续：细比例条）
- 导出 ShareSheet（可第二批）
- 业务规则、数据模型变更

- `TimeLedger/Views/Today/TimeListView.swift` — 去底栏四格、确认文案、密度
- 可选：`Utilities` 下轻量 `TLTheme` / 间距常量

## 8. 已锁定决策记录

| 决策 | 结论 |
|------|------|
| 方向 | A 系统清爽结构 + D2 柔和视觉 |
| 未记录字号 | 正常/偏小，禁止英雄数字 |
| 未记录 vs Segment | 分层：状态条 + 下一行整宽 Segment |
| 主屏统计 | 只保留未记录 |
| 项目密度 | 紧凑多行，热区不低于 ~44pt |
