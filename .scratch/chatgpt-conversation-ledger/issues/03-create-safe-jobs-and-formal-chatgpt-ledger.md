# 03 — 生成安全任务与正式 ChatGPT 账本

**What to build:** 用户选择会话后，系统能生成不可变的处理任务，并只在候选通过校验且用户明确确认后把语义结果一次性写入正式 ChatGPT 账本；任何失败、中断或重复执行都不误把原始消息标为已处理。

**Blocked by:** 02 — 读取归档并识别待处理版本.

**Status:** completed

- [x] 任务只包含所选会话的未处理消息版本及有限只读上下文，并冻结输入和账本基线摘要。
- [x] 候选必须完整覆盖输入或给出忽略原因，且通过来源、主题目标、摘要和重复导入校验后才能确认应用。
- [x] 正式保存、回执、幂等、旧候选、部分写入恢复和用户锁定内容均有验证；再次应用同一任务不产生变化。
