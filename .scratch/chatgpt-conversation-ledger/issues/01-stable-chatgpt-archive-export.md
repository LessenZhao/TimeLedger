# 01 — 稳定导出 ChatGPT 原始消息

**What to build:** 用户成功归档一个 ChatGPT 会话时，现有可读归档之外还会得到同一会话的稳定结构化副本；该副本保留会话身份、原始消息身份、角色、时间和正文，供后续账本安全引用，并让旧归档继续可读。

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] 一次成功归档同时产出可读归档和包含稳定会话/消息身份的结构化会话副本；重复导出更新同一会话而不产生副本。
- [x] 两种归档写入路径均保持同一结构化格式，并以原子方式发布；附件 data URL 不进入副本。
- [x] 旧归档索引在没有结构化副本信息时仍可读取，自动验证证明身份、角色、时间和正文完整保留。
