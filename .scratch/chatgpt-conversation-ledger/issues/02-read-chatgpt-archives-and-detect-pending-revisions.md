# 02 — 读取归档并识别待处理版本

**What to build:** 用户在账本中查看已归档 ChatGPT 会话时，系统能根据原始消息版本和已接受记录准确显示已处理、待处理、部分处理或需要重新导出，而不是依赖会漂移的状态副本。

**Blocked by:** 01 — 稳定导出 ChatGPT 原始消息.

**Status:** completed

- [x] 会话和消息能以稳定顺序读取；缺少结构化副本或副本无效时，用户看到“需要重新导出”而非空会话。
- [x] 内容哈希用于区分已接受版本、追加消息和已变更消息；新会话、完全处理、追加、变化和缺少副本均有验证覆盖。
- [x] 包含 18 条已接受消息与 4 条新增消息的夹具准确显示为 `18 processed / 4 pending`。
