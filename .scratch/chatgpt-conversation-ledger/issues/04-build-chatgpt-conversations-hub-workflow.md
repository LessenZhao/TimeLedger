# 04 — 增加 Mac ChatGPT 对话工作流

**What to build:** 用户可在 Mac App 的独立“ChatGPT 对话”入口按日期和处理状态查看归档会话、多选材料、查看已处理与待处理数量，并生成只处理所选未处理版本的任务和精确 Skill 命令，不影响既有工作沉淀功能。

**Blocked by:** 03 — 生成安全任务与正式 ChatGPT 账本.

**Status:** completed

- [x] 独立入口清楚显示归档路径错误和需要重新导出的会话，且日期筛选只影响可见内容，不暗中扩大或缩小处理范围。
- [x] 用户可以多选会话并生成不可变任务，界面显示可复制的精确 `$chatgpt-ledger process <job-id>` 命令。
- [x] 选择一个部分处理会话时，任务仅含其待处理消息版本，并由自动验证覆盖该完整操作。
